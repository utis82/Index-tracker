ℹ️ Informations sur l'import

📋 Format attendu :

  • Feuille Excel nommée "1. BDD"
  • Colonnes 1-8 : Métadonnées (Type, Source, Désignation, etc.)
  • Colonnes 9+ : Dates au format français (ex: mars-21, févr-24)

🔧 Modes d'import :

  • Mode ajout (par défaut) : Ajoute les nouvelles données et met à jour les existantes
  • Mode remplacement : Supprime complètement les anciennes données avant l'import

⚠️ Important :

  • L'import peut prendre plusieurs minutes selon la taille du fichier
